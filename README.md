# 📥 ZeroxDownloader

بات دانلودر تلگرام — لینک بفرست، فایل بگیر.

## پشتیبانی

- 🟢 **یوتیوب** → ویدیو MP4 (تا 1080p) یا آهنگ MP3
- 🎵 **اسپاتیفای** → ترک، آلبوم و پلی‌لیست → MP3 با تگ کامل ID3
- 📱 **تیک‌تاک** → ویدیو بدون واترمارک

## اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن بات از @BotFather"
python3 bot.py
```

## دستورات

| دستور | کار |
|-------|-----|
| `/start` | شروع و راهنما |
| `/song` | لینک بعدی به‌صورت MP3 |
| `/video` | لینک بعدی به‌صورت ویدیو |
| `/videobox 480` | تغییر کیفیت ویدیوی یوتیوب |

## ویژگی‌ها

- تشخیص خودکار پلتفرم از روی لینک
- آلبوم/پلی‌لیست اسپاتیفای → همه ترک‌ها پشت‌سرهم
- جستجوی هوشمند یوتیوب: نزدیک‌ترین نتیجه به طول ترک اصلی (نسخه‌های 1 Hour رد می‌شن)
- آپلود هم‌زمان چند کاربر (async)
- گزارش پیشرفت به‌صورت پیام‌های زنده
- محدودیت 49MB با پیام راهنما + حذف خودکار فایل‌ها

## نکته یوتیوب

یوتیوب به IPهای دیتاسنتر گاهی بات‌چک می‌ده (موقتیه). اگر خطا دیدی چند ساعت بعد امتحان کن، یا بات را روی سیستم شخصی اجرا کن که با IP خانگی همیشه کار می‌کند. پشتیبانی cookies هم داخل بات هست:

```
export YOUTUBE_COOKIES="مسیر/cookies.txt"
```
