# 📥 بات دانلودر تلگرام

بات دانلود از یوتیوب، اسپاتیفای و تیک‌تاک — لینک را بفرست، فایل را بگیر.

## امکانات

- 🟢 **یوتیوب** → ویدیو MP4 (کیفیت قابل تنظیم 144p تا 1080p) یا آهنگ MP3
- 🎵 **اسپاتیفای** → متادیتای ترک (نام، خواننده) + جستجو در یوتیوب + MP3 با تگ کامل (ID3)
- 📱 **تیک‌تاک** → ویدیو بدون واترمارک
- تشخیص خودکار پلتفرم از روی لینک
- محدودیت خودکار 49MB (محدودیت آپلود بات تلگرام)

## اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن بات از @BotFather"
python3 bot.py
```

## دستورات

| دستور | کار |
|-------|-----|
| `/start` | شروع و راهنما |
| `/song` | لینک بعدی به‌صورت MP3 (برای یوتیوب) |
| `/video` | لینک بعدی به‌صورت ویدیو |
| `/videobox 480` | تغییر کیفیت ویدیوی یوتیوب |

## نکته مهم: یوتیوب و cookies

یوتیوب IPهای دیتاسنتر (سرورها) را «بات» تشخیص می‌دهد. اگر روی سرور اجرا می‌کنی:

1. افزونه **Get cookies.txt LOCALLY** را در کروم نصب کن
2. به [youtube.com](https://youtube.com) برو (با اکانت لاگین)
3. cookies.txt را export کن
4. فایل را کنار `bot.py` بگذار (بات خودکار می‌خواند)

**روی سیستم شخصی (IP خانگی)** معمولاً بدون cookies هم کار می‌کند.

تیک‌تاک و اسپاتیفای به cookies نیاز ندارند.

## معماری

- `bot.py` — تمام منطق (تشخیص پلتفرم، دانلود، تبدیل MP3، آپلود)
- دانلود موازی برای سرعت + حذف خودکار فایل بعد از ارسال
- پشتیبانی هم‌زمان چند کاربر (async)
